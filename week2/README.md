# Week 2 — Data Analysis and Machine Learning

This folder contains the Week 2 notebooks, SQL exercises, and saved model
comparison results.

## Files

- `ab_test.ipynb` — A/B testing exercise.
- `regression.ipynb` — Regression exercise.
- `classification.ipynb` — Classification exercise.
- `beat_the_baseline.ipynb` — Baseline comparison exercise.
- `model_comparison.ipynb` — Model comparison work.
- `week2_model_comparison_results.csv` — Saved comparison results.
- `queries.sql` — SQL queries.

## Running the Notebooks

Open the notebooks in a Jupyter-compatible editor and select a Python
environment containing the libraries imported by each notebook.

Review the data-loading cells before running. Dataset locations and required
packages must match the local environment. Run cells in order.

## SQL Dataset

The local `Chinook_Sqlite.sqlite` file is excluded from Git.
If `queries.sql` references the Chinook database, obtain the matching dataset
and configure the SQLite connection locally.

## Results and Limitations

Use the outputs and saved CSV for the recorded experiment results.
Do not interpret a training score alone as evidence of generalization.
Review the notebook's split, metric, preprocessing, and baseline when
explaining a comparison.

Notebook execution from a fresh environment has not been verified as part
of the Week 4 capstone setup check.
