# Day 3 files

1. Open `day3_cleaning.ipynb` in VS Code.
2. Select the Python kernel if prompted.
3. Run **Run All** and wait for every cell to finish.
4. Check the printed airport revenue percentage and the merge row counts.
5. The notebook creates `cleaned.csv` and `cleaning_log.md` in the notebook's current working folder. If VS Code uses the repository root as the working folder, move the generated files into `week1/` before committing.
6. Review the notebook and be ready to explain each decision. Do not commit until the notebook has been run and outputs are visible.
